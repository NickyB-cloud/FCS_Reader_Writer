FCS READER / WRITER (STANDALONE MODULE)
=======================================

What this folder does
---------------------
FCS_Reader_Writer.py is the pure-Python FCS reader and writer built into my
spectral flow cytometry pipeline, pulled out into one file you can download
and use on its own. It needs only
numpy and pandas -- no FCS library (fcsparser, FlowIO, FlowCal, FlowKit ...).

Reads  : FCS 3.0 / 3.1 / 3.2 list-mode files
         $DATATYPE I (8/16/32/64-bit unsigned), F (float32), D (float64)
         either byte order ($BYTEORD 1,2,3,4 or 4,3,2,1)
         keywords with or without the leading "$", any TEXT delimiter,
         doubled (escaped) delimiters, data offsets in the header or in
         $BEGINDATA/$ENDDATA (files over ~100 MB)
Writes : FCS 3.0, float32, little-endian, keywords in Cytek Aurora order

Values are returned exactly as stored (linear). The reader does NOT apply
$PnE log decoding, $PnG gain, compensation ($SPILLOVER) or any transform.
Files with different $PnB bit depths per channel are refused with an error.


Use it in your own script
-------------------------
Put FCS_Reader_Writer.py next to your script (or on your PYTHONPATH), then:

    from FCS_Reader_Writer import load_fcs_as_dataframe, read_fcs, write_fcs_3_0

    df = load_fcs_as_dataframe("sample.fcs")         # pandas DataFrame,
                                                     # one column per channel
    events, channels, meta = read_fcs("sample.fcs")  # numpy array (events x
                                                     # channels), channel names,
                                                     # dict of TEXT keywords
    meta.get("$fil"), meta.get("$date")              # keys are lower-case

    gated = df[df["FSC-A"] > 50000]
    write_fcs_3_0("sample_gated.fcs", gated)         # DataFrame -> .fcs

Channel names come from $PnN, then $PnS, then "Ch1", "Ch2" ...
When writing, "|" in a column name becomes "/" ("|" is the TEXT delimiter).


Use it from the command line
----------------------------
    python FCS_Reader_Writer.py sample.fcs              # events, channels,
                                                        # min/median/max per channel
    python FCS_Reader_Writer.py sample.fcs --keywords   # + every TEXT keyword
    python FCS_Reader_Writer.py sample.fcs --csv out.csv   # + export to CSV


Checks done before release
--------------------------
- Writer output is byte-identical to the writer inside the pipeline scripts
  (small file and a >100 MB file that needs $BEGINDATA/$ENDDATA).
- Reader returns identical arrays, names and keywords to the pipeline
  reader on real Cytek Aurora raw and unmixed files, and correctly reads
  hand-built 8/16/32-bit integer, float32 and float64 files in both byte
  orders.
